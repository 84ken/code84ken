■ 原画置き場（sketches フォルダ）

子どもがかいたアイディアの絵・企画書の写真を、ここに入れてください。
Web用に軽くしたJPG（横1400px程度）を置くのがおすすめ。
iPhoneのHEIC原本は originals/ に保管しています。

games.js の該当ゲームの sketch 欄に指定すると、
カードにポラロイド風に飾られます（クリックで拡大表示）。

1枚のとき:
  sketch: "sketches/kuma-egao.jpg",

複数のとき（label は写真の下のキャプション）:
  sketch: [
    { src: "sketches/yari-kikaku1.jpg", label: "きかくしょ" },
    { src: "sketches/yari-boss.jpg",    label: "ボスせっけいず" },
  ],
